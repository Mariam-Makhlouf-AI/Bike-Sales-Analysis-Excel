# 🚴 Bike Sales Analysis Dashboard

## 📌 Project Overview

This project analyzes bike sales and customer purchasing behavior using Microsoft Excel.

This project was developed as part of my learning journey with the Digital Egypt Pioneers Initiative (DEPI).

## 🎯 Project Objectives

* Analyze customer purchasing behavior.
* Compare average income by gender and bike purchase status.
* Explore bike purchases across different age groups.
* Analyze customer distribution by region and education level.
* Study the relationship between commute distance and bike purchases.
* Build an interactive dashboard using Excel.

## 🛠️ Tools & Skills

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Interactive Slicers
* Data Analysis
* Data Visualization
* Dashboard Design

## 📊 Dashboard Features

* Customer purchasing behavior analysis.
* Income analysis by gender and bike purchase status.
* Analysis of bike purchases across age groups.
* Interactive filtering using slicers.
* Visual exploration of customer demographics.

## 💡 Key Learnings

This project helped me improve my skills in data analysis, Pivot Tables, Pivot Charts, and interactive dashboard creation using Microsoft Excel.
